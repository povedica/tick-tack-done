# TTD-AUD-100 — Enlaces de tareas

RF-201, RF-202, RF-2001 y RF-2002. TaskLink con owner, tarea, URL normalizada única, título y origen auto/manual; migración generada con pnpm db:migrate sobre ttd_r80 y bajada/reaplicación comprobadas transaccionalmente (100-rollback-proof.sql).

Tests rojos previos: extractor ausente; SSRF IPv6 hexadecimal aceptaba privadas; Playwright no encontraba chips. Ahora pasan 2 pruebas de dominio, 7 de destinos/unfurl, 34 del servicio MCP y una integración PostgreSQL MCP/REST de reconciliación/owner/validación/contador. Cuatro Playwright verifican 24/32 px, actualización remota ≤2 s, URL inválida y alta manual. La prueba remota usa el mismo polling que un cambio por MCP; no demuestra una sesión externa de producción.

Las capturas antes conservan la pantalla original; después desplaza el detalle para mostrar los dos chips. Favicon solicitado únicamente por el navegador a Google S2. El unfurl manual falla sin impedir guardar; los automáticos usan dominio/URL, ya que el título remoto es opcional. No se descarga ni guarda ningún favicon ni binario. Los enlaces privados se guardan sin acceso de red. El servidor fija IP pública tras DNS y revalida cada salto; plazo total incluyendo DNS, tipo HTML y tamaño acotados.

Limitaciones: no se ha realizado prueba con proveedor MCP externo/staging; las pruebas son locales con usuarios sintéticos. La aceptación global de la PR sigue pendiente.
